## <span id="jobs-toc-heading-1" data-jobs-toc="v2">🔥 <font id=前言>前言</font></span><!-- jobs-toc:heading-end -->

批量隐藏或恢复 [**Finder**](https://support.apple.com/guide/mac-help/get-to-know-the-finder-mchlp2605/mac) 中的文件扩展名显示。

仅改变普通文件的显示属性，不更名、不改正文；排除开发缓存、第三方目录和符号链接。

| 入口速览 | 实际行为 |
| --- | --- |
| 操作顺序 | 拖入多个目录 → 回车隐藏 / `show` 恢复 → NUL 遍历 → 汇总失败。 |
| 交互 | 自述回车继续；模式回车隐藏，输入 show 恢复。 |
| 范围 | 仅改变普通文件的显示属性，不更名、不改正文；排除开发缓存、第三方目录和符号链接。 |

## <span id="jobs-toc-heading-8" data-jobs-toc="v2">五、操作流程 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

1、先展示内置自述，确认失败则停止，不进入业务。

2、拖入一个或多个目录；拒绝根目录、整个用户主目录及明确的排除目录。

3、模式回车表示隐藏，输入 `show` 表示恢复显示，其它输入报错退出。

4、从 PATH 或 `xcrun --find SetFile` 寻找并验证 SetFile；缺少工具时提示准备 Command Line Tools，不自动安装。

5、NUL 遍历普通文件，递归跳过 `.git`、`node_modules`、`Pods`、`.dart_tool`、`build` 和 `DerivedData`。

6、逐项设置 `SetFile -a E` 或 `-a e`；失败不显示成功，最后汇总总数与失败数，存在失败时返回非零。

- Finder 显示受文件属性及 Finder 的全局显示设置共同影响；文件名和内容保留。
- 不自动清理目录或修改权限；部分文件无权限时保留原状态并报告。
